# Pixel Editor

A native, lightweight pixel art editor dock for Godot. Frame-based animation, onion skinning, mirror painting, and PNG / Spritesheet / SpriteFrames export.

## Requirements

- Godot 4.3 or newer

## Installation

1. Copy the `addons/pixel_editor/` folder into your project's `addons/` directory.
2. Open your project in Godot.
3. Go to **Project → Project Settings → Plugins**.
4. Enable **Pixel Editor**.

The editor dock appears on the right side of the editor.

## Features

- **Drawing tools** — Pencil, Eraser, Fill.
- **Frame-based animation** — create and edit multiple frames in a timeline.
- **Onion skinning** — see adjacent frames while drawing.
- **Mirror painting** — symmetrical drawing along the X/Y axes.
- **Undo / Redo** — full history support.
- **Export** — PNG, Spritesheet, and SpriteFrames.
